# run-agent

GitHub Action used by Wopee project workflows (`uses: <org>/run-agent@v1`).

`main` and `v1` are mirrored into each tenant org by the infra mirror's sync, so a change reaches a tenant at its next sync / Release. See the [release flow](https://github.com/autonomous-testing/infra/blob/main/docs/release-flow.md).
